Publicar

Descarga el archivo y súbelo al repositorio. En cuanto GitHub lo despliegue, el portal lee de él en vez de los datos de muestra.

Este panel no publica solo. Genera un archivo que tú subes a GitHub. Por eso da igual que panel.html esté a la vista de cualquiera: quien lo abra podrá teclear lo que quiera en su navegador, pero no puede tocar tu web, porque publicar exige subir el archivo a tu repositorio con tu cuenta.

Clasificación tal y como saldrá

datos.json

Cómo subirlo

1. Descarga el archivo. 2. En tu repositorio, Add file → Upload files. 3. Arrastra datos.json a la raíz. 4. Commit changes. En un par de minutos está en línea.

Para que el portal lo lea, en index.html deja la función de carga así:

async function cargarCompeticion(id){
  const r = await fetch("datos.json", {cache:"no-store"});
  if(!r.ok) return construir(CATALOGO.find(c=>c.id===id));
  return await r.json();
}

Si el archivo no existe todavía, sigue enseñando los datos de muestra en lugar de romperse.
